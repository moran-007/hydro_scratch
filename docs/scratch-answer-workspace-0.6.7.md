## 修复内容

- 修复比赛/作业题面旧 Scratch 动作区中的编辑器链接不会携带 `tid` 的问题。
- 编辑器入口增加 Referer 兜底识别：从比赛题面进入时，即使 URL 本身缺少 `tid`，也会尝试从来源题面恢复比赛上下文。
- 保持窗口布局不变，不新增可见按钮，不影响 Scratch 顶栏、题目弹窗和成绩卡布局。

## 部署后检查

1. 打开比赛题目列表，进入 Scratch 题面。
2. 检查题面中的 `进入 Scratch 答题页面` 链接是否变为 `/scratch/problem/<pid>/editor?tid=<contestId>`。
3. 从该入口进入编辑器后提交，确认成绩弹窗、比赛题目列表和榜单同步更新。
