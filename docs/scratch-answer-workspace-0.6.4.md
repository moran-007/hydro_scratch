# Scratch 答题页 0.6.4 交互说明

## 学生入口

普通 Hydro 题面会自动追加 Scratch 答题入口：

- `进入 Scratch 答题页面`：进入内嵌 Scratch 编辑器答题。
- `查看我的提交`：查看当前学生在本题的 Scratch 提交记录。

教师打开题面时还会看到：

- `查看提交 / 手动评分`
- `编辑 Scratch 题目`

## 答题页布局

Scratch 答题页现在以 Scratch 编辑器为主区域，外层不再显示单独的编辑器标题栏。

- 左侧题面是可折叠抽屉。
- 点击题面头部的 `收起` 后，题面会变成窄导航栏。
- 点击窄导航栏上的 `题目` 后，题面恢复。
- 拖动题面右侧边缘可以调整题面宽度，宽度会保存在浏览器本地。
- 外层不再提供重复的 `提交测评`，提交统一使用 Scratch GUI 内部按钮。
- Scratch GUI 顶栏的 `查看题目` 会在 Scratch 内部打开题目面板，并同步创建纯文本工作区注释作为兜底。

## 成绩展示

学生点击 `提交测评` 后，页面会：

1. 从 Scratch GUI 导出当前 `.sb3`。
2. 上传到 `/scratch/submit/:pid`。
3. 使用返回的 `reportUrl` 读取当前提交报告。
4. 弹出成绩结果窗口，同时更新右下角 `最近成绩` 卡片。

如果自动判题关闭或仍在等待人工评分，成绩位置会显示等待状态。

`最近成绩` 卡片可以手动隐藏。右下角 `⋯` 设置工具条可以整体拖动，位置会按题目保存在浏览器本地，避免遮挡学生继续搭积木。

## Scratch 内部题目面板

父页面会读取 Hydro 题面，把入口按钮、提交链接、查看原题等外层控制项过滤掉，再发送给 Scratch 编辑器。

点击 Scratch GUI 顶栏的 `查看题目` 后，编辑器会打开一个 Scratch iframe 内部的题目面板。这个面板支持题面图片、表格和常规 HTML 内容，图片地址会被转换为可加载地址。

同时，编辑器会在当前角色或舞台的工作区中创建/打开一个纯文本 Scratch 注释，作为无法显示 HTML 时的兜底提示。注释内容不包含 `进入编辑器`、`查看原题`、`提交测评` 等入口。

Scratch/Blockly 默认右下角缩放放大镜控件已隐藏，减少对学生搭积木区域的遮挡。

## 暂存逻辑

当前暂存策略：

- 进入答题页时优先检查 `/scratch/problem/:pid/draft`。
- 如果存在草稿，加载 `/scratch/problem/:pid/draft/project`。
- 如果没有草稿但存在题目模板，加载模板。
- 手动点击 `保存草稿` 会保存当前作品。
- 开启 `自动暂存` 时，每 120 秒自动保存一次。
- 提交成功后，会把本次提交作品同步保存为当前草稿。

这样学生第二次进入同一题目时，可以继续编辑上一次保存或提交的作品。

## 主题色

右下角 `⋯` 更多菜单提供 `主题色` 选择器。

- 颜色保存在浏览器本地，按题目区分。
- 外层答题页立即生效。
- 如果 Scratch 编辑器与 Hydro 同源，会尝试同步修改 Scratch 顶栏主色。
- 如果 Scratch 编辑器是跨域地址，则只保留外层主题色。
- 更多菜单可以点击 `收起面板` 或点击空白区域关闭。

图片主题上传暂未加入，因为它需要服务端存储、权限校验、文件类型校验和跨页面资源安全处理。

## 验证建议

1. 学生进入普通题面，确认能看到 `进入 Scratch 答题页面`。
2. 进入答题页后切换题面收起、打开，并拖动调整宽度。
3. 在 Scratch 顶栏点击 `查看题目`，确认 Scratch 工作区内部出现题目注释。
4. 搭一个简单作品，点击 `保存草稿`。
5. 刷新页面，确认作品恢复。
6. 修改作品后点击 `提交测评`。
7. 确认提交后出现成绩弹窗，右下角最近成绩卡片可隐藏。
8. 拖动右下角 `⋯` 工具条，确认设置面板可移动且自动暂存、主题色、查看原题等入口可以收起。
9. 关闭页面后再次进入，确认能继续编辑最近作品。

## GUI 稳定性与全屏

- 语言菜单切换时不再强制滚动外层页面，避免打开语言列表后页面乱跳或翻页。
- 语言项点击会阻止多余事件冒泡，减少菜单关闭与语言切换互相干扰的情况。
- Scratch 编辑器内部右上侧新增 `全屏` 按钮，优先让 iframe 内部进入浏览器全屏；如果浏览器策略限制 iframe 全屏，会请求外层 Hydro 答题工作区进入全屏。
- 全屏状态下答题工作区、Scratch 容器和 iframe 高度统一为 `100vh`，宽度为 `100vw`。
