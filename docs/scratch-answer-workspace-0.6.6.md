# Scratch 答题页 0.6.6 更新说明

## 成绩同步

- Scratch 提交后会统一触发 Hydro 成绩回写。
- 普通题目状态会被刷新，训练页重新进入后可读取最新完成状态。
- 比赛和作业提交会写入对应 journal，列表和榜单可获得本次成绩。
- 自动判题失败或等待手动评分时，也会写入等待状态，避免“有记录但上下文没有提交状态”。
- 手动评分会先保底更新 record，再通过 Hydro judge 回调刷新题目、比赛和作业状态。

## 提交后返回

提交成功弹窗现在包含：

- 查看提交记录
- 返回题目
- 返回列表
- 继续答题

比赛入口优先返回比赛题目列表，作业入口返回作业详情页。训练入口可通过 `training`、`trainingId` 或 `trid` 查询参数指定训练详情页；未指定时会保留同源来源页作为返回题目入口。

## Scratch 内部题目窗口

- 点击 Scratch 顶栏“查看题目”打开内部题目窗口。
- 窗口标题栏可拖动。
- 右下角可拖动调整窗口宽度和高度。
- 窗口会限制在当前视口内，减少遮挡和拖出屏幕的问题。
