# 参考题型改写 Scratch 题包

本目录包含 12 道重新设计的 Scratch 题包：6 道任务题、6 道算法题。题型参考公开题库页面的常见编程考点，题面、测试点和变量命名均已重新整理。

- `llscratcht01` 任务题：星际航线定位
- `llscratcht02` 任务题：派对礼物变装
- `llscratcht03` 任务题：森林小鸟接力飞行
- `llscratcht04` 任务题：键盘赛车训练
- `llscratcht05` 任务题：画笔四宫格图案
- `llscratcht06` 任务题：克隆星星雨
- `llscratcha01` 算法题：考试日期格式转换器
- `llscratcha02` 算法题：两位数 3 的倍数判定
- `llscratcha03` 算法题：藏头诗提取器
- `llscratcha04` 算法题：大苹果统计器
- `llscratcha05` 算法题：成绩等级播报器
- `llscratcha06` 算法题：列表筛选与重排

导入方式：进入 Hydro scratch 域题目导入页，逐个上传 `*.scratch-problem.zip` 文件即可。
